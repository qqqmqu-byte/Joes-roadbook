## 🎯 这是什么

一份**真实走过**的新疆南疆 11 天自驾路书（武汉出发，喀什 → 帕米尔高原 → 库车 → 阿克苏 → 返程），把行程拆到了**小时级**：

- 几点出发、几点到、停留多久
- 每个景点的**门票、海拔、最佳机位**
- 每天**避坑提醒**：边防证、加油、高反、无信号路段
- 预算估算、装备清单、穿搭指南

但它的价值不只是这份行程本身 —— **它是一份"路书范本"**：打开就能看到一份好路书应该长什么样、要包含哪些信息，并照着搭出你自己的。

> 💡 不需要安装任何东西，浏览器打开即用，离线也能看（PWA）。

## 📖 怎么用

### 1. 打开即引导

首次打开会自动弹出 3 步引导，告诉你：这是什么、你能怎么用、怎么搭自己的。

也可以随时在 **「我的」** 页底部点「重新看一遍使用引导」再看一次。

### 2. 五个 Tab 各司其职

```
[ 行程 ] [ 地图 ] [ 美食 ] [ 安全 ] [ 我的 ]
```

- **行程**：默认看总览（倒计时/进度/快捷入口），点天数切到单日详情
- **地图**：点上方 D1-D11 筛选某天路线，点地图标记看详情 + 一键导航
- **美食 / 安全**：按城市/主题浏览，都是干货
- **我的**：你的收藏和笔记，见下

### 3. 收藏：把有用的攒下来

浏览时，**景点卡片**和**美食卡片**右上角有 ⭐ 收藏按钮：

```
喀什古城东门  D2 · 10:00          [⭐]
```

点一下收藏，进 **「我的」** 页就能看到所有收藏，按天归档。这就是你下一个行程的素材库。

### 4. 笔记：随手记灵感

「我的」页有笔记输入框，记下任何想法：

> 例：喀什 9 月底的杏子最好吃 / 冰川那天一定要租防滑链 / 预算超了的话砍掉木吉…

## 🧭 怎么照着搭一份自己的路书

这份路书的结构是通用的，**四步**替换成你的目的地：

| 步骤 | 做什么 | 对应范本里的 |
|---|---|---|
| 1. 定框架 | 天数、起点终点、交通方式 | 11 天 / 武汉出发 / 飞机+自驾+火车 |
| 2. 排路线 | 按地理位置串点，每天车程 4-6 小时 | D4 白沙湖→木吉→塔县 |
| 3. 填细节 | 每个点标注：时间、停留、门票、海拔、避坑 | 每天的 items 列表 |
| 4. 加预案 | 天气差、封路、身体不适怎么办 | 每天底部「行程建议」+ 安全页 |

**照抄结构，替换内容** —— 这就是一份专业路书的全部秘诀。

## 🔧 本地部署

这是一个**单文件 HTML** 应用，无构建、无依赖（仅 CDN 引入 Tailwind/Leaflet）：

```bash
# 方式一：直接双击打开 index.html

# 方式二：起个本地静态服务
python -m http.server 8080
# 打开 http://localhost:8080
```

> ⚠️ 地图瓦片依赖网络（高德/OSM/ArcGIS 自动切换），首次建议联网打开；行程内容本身可在离线时浏览（PWA）。

### 项目结构

```
├── index.html          # 全部代码（HTML + CSS + JS 单文件，约 110KB）
├── build_v3.py         # 构建脚本（从线上版做增强：引导层/收藏/我的页）
├── verify_v3.py        # 语法与结构校验
└── runtime_test.js     # 运行时逻辑测试（含 XSS 防护测试）
```

## 🛠 技术栈

- **纯前端**：原生 JS + Tailwind CSS（CDN）+ Leaflet（地图）

- **PWA**：内联 manifest，可添加到主屏幕
