# 🗺️ 南疆路书 · Joes-roadbook

> 一份**单文件、可离线、可装到主屏**的自驾游路书网页。把 11 天的南疆行程——喀什古城、帕米尔高原、白沙湖、盘龙古道、慕士塔格冰川、库车大峡谷——浓缩成一个打开即用的手机端旅行助手。

## ✨ 功能特性

- **📅 11 天时间轴**：D1–D11 逐日卡片，含当天海拔区间、行驶里程、强度星级（★）与住宿费用。
- **⏱️ 当日倒计时 / 回到今天**：基于 `tripStart` 自动计算「还有 N 天出发」，并在行程进行中一键跳回「今天」，过期自动进入回顾模式。
- **🗺️ 交互式地图轨迹**：用 Leaflet 绘制每日行车路线与景点标注，支持高德 / OpenStreetMap / ArcGIS 多瓦片源容错切换；按天筛选查看。
- **🧭 一键导航**：每个地点可拉起高德 / 百度 / 腾讯 / Apple 地图导航（自动按 WGS84 坐标跳转）。
- **🏔️ 海拔 · 门票速查表**：帕米尔主要景点的海拔、门票、购票渠道、亮点、建议停留一目了然。
- **🍜 美食 / 避坑 / 必去标签**：每条行程按 `必去 / 出片 / 美食 / 避坑 / 交通` 五色标签分类，行程规划与现场执行两用。
- **📱 PWA 可装主屏**：内联 manifest，支持「添加到主屏幕」，像 App 一样全屏打开、离线查看。
- **🎨 精致的移动端 UI**：玻璃拟态卡片、品牌色系统、安全区适配、动效过渡，专为手机竖屏优化。

## 🗺️ 技术栈

| 能力 | 方案 |
| --- | --- |
| 结构 / 样式 | 单文件 `index.html`，[Tailwind CSS](https://tailwindcss.com)（CDN） |

> 整个项目只有 **一个 `index.html` 文件**，零依赖安装、零构建，丢到任意静态服务器或直接双击即可运行。

## 🚀 快速开始

**方式一：直接打开**
双击 `index.html` 用浏览器打开即可（手机可用浏览器打开，或「添加到主屏幕」当 App 用）。

**方式二：本地起一个静态服务（推荐，地图瓦片加载更稳）**
```bash
# 在项目目录下
python -m http.server 8080
# 然后浏览器访问 http://localhost:8080
```

**部署到公网**
把 `index.html` 丢到任意静态托管（GitHub Pages / Vercel / Netlify / 你自己的服务器）即可。本项目就是这么部署的。

## ✏️ 如何改造成自己的路书

本项目的数据是**半数据驱动**的：行程内容集中在 `index.html` 的 `days` 数组中，改它就能套用自己的行程，无需动渲染逻辑。

### 1. 改行程：编辑 `days` 数组（约第 246 行）

每个元素是一天的行程，字段含义：

| 字段 | 含义 | 示例 |
| --- | --- | --- |
| `day` | 第几天 | `1` |
| `date` | 日期描述 | `'9月下旬·周四'` |
| `title` | 当天标题 | `'抵达喀什·入住希尔顿'` |
| `icon` | 标题前 emoji | `'🛬'` |
| `alt` | 海拔区间 | `'1300→3500→3100m'` |
| `drive` | 当日行驶里程 | `'450km'` |
| `intensity` | 强度星级（★越多越累） | `'★★★★★'` |
| `stay` | 住宿名称 | `'全季酒店 千草滩景区店'` |
| `stayPrice` | 住宿价格（可写房型） | `'¥1828'` 或 `'灵动大床房'` 或 `'—'` |
| `items` | 当天时间线条目（见下） | `[...]` |
| `tip` | 每日贴士 | `'高原第一晚！不洗澡不饮酒'` |

`items` 中每条：
| 字段 | 含义 | 示例 |
| --- | --- | --- |
| `t` | 时间 | `'07:00'` / `'上午'` |
| `p` | 地点 / 事件名 | `'白沙湖（北岸）'` |
| `tr` | 条目图标 emoji | `'🚗'` |
| `tag` | 类型，决定颜色与标签 | `must`/`photo`/`food`/`warn`/`transit` |
| `d` | 描述（可带 `[必去][出片][美食][避坑]` 标记） | `'[绝佳机位] 北岸免费、人少、能走到水边！'` |

> `tag` 取值 → 中文标签：`must`=必去，`photo`=出片，`food`=美食，`warn`=避坑，`transit`=交通。

### 2. 改地图打点：编辑 `poiCoords`

`poiCoords` 是「地点名 → 经纬度」的映射，格式为 `[纬度, 经度]`：

```js
const poiCoords = {
  '白沙湖': [38.55, 75.12],
  '慕士塔格冰川': [38.48, 75.10],
  // ...
};
```

只有出现在 `poiCoords` 里的地点才会在地图上显示标注与连线，请确保 `items[].p` 的地点名能在 `poiCoords` 中匹配到。

### 3. 改行程日期：编辑 `tripStart` / `tripEnd`（约第 472 行）

这两个时间驱动「倒计时」和「回到今天」功能，请改成你自己的出发 / 返程时间：

```js
const tripStart = new Date('2026-09-25T00:00:00+08:00');
const tripEnd   = new Date('2026-10-05T23:59:59+08:00');
```

### 4. 改标题与品牌色

- `<title>`、`meta description`、`theme-color`（文件顶部）改为你的路书名与主题色。
- 想换配色：改 `<style>` 里的 `--terracotta*` CSS 变量，以及 Tailwind 配置中的 `brand` 色板。

### 5. ⚠️ 重要：替换 / 移除腾讯 beacon 埋点

`index.html` 第 177–191 行引用了**作者本人的腾讯 beacon 统计**（`beacon.cdn.qq.com`）。如果你公开分享或部署自己的版本，请：

- **移除** 这两段 `<script>`，或
- **替换** 成你自己的统计 ID（否则访问数据会混进原作者账号）。

## ⚠️ 已知限制 / TODO

- **数据未彻底抽离**：行程数据写在 `index.html` 内，复用需要懂一点 JS。下一步计划把 `days` / `poiCoords` 抽成独立的 `data.js`，实现「改一份 JSON 即生成一份路书」。
- **依赖外部 CDN**：Tailwind、Leaflet、Google Fonts 及地图瓦片均来自公网。首次打开需联网；离线时若已缓存过则可正常显示，但字体 / 样式 / 地图可能降级。
- **统计埋点耦合**：beacon 代码需手动替换（见上）。
- **地图边界与合规**：地图瓦片来自第三方服务，跨境 / 边界区域的标注以瓦片提供方为准，本项目不保证地图内容的政治边界准确性。
- **无构建 / 无测试**：纯静态手写，未做自动化测试。

欢迎提 Issue / PR 一起把「填数据即生成路书」的能力做出来。
